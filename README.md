# Fullstack Playground

This repository is a monorepo containing multiple small full-stack projects.
Each project is self-contained and demonstrates different architectural and
technological patterns.

## Tech Stack
- Java / Spring Boot
- Vue.js or React
- Keycloak (Auth / BFF patterns)
- Docker & Docker Compose
- PostgreSQL

## Projects
- todo-app  
  Full-stack TODO application (Spring Boot + Vue.js)

- bff-keycloak-demo  
  Backend-for-Frontend example with Spring Boot, Keycloak and Vue

Each project contains:
- backend (Spring Boot)
- optional frontend (Vue.js or React)
- Docker setup for local development
